# Kamiro glossary

| Term | Means | Not | Français |
| --- | --- | --- | --- |
| Address bar | The path in the toolbar: crumbs, or a field when typing | Path bar, breadcrumb bar, location bar | Barre d'adresse |
| Crumb | One folder name in the address bar | Segment, breadcrumb | Élément du chemin |
| Item | A file, folder, package or alias in a list | Entry, node, object | Élément |
| Details view | Rows with columns | List view, table view | Présentation en détails |
| Icon view | Grid of icons or thumbnails | Grid view, tiles | Présentation en icônes |
| Column view | Folders left to right | Miller columns, browser | Présentation en colonnes |
| Inspector | Pane on the right with the selection's details | Details pane, preview pane, info panel | Inspecteur |
| Properties | Window with one item's full details (⌘I) | Get Info, info window | Propriétés |
| Pinned | Sidebar section of folders the user chose | Favorites, Quick access | Épinglés |
| Home | Sidebar page with pins, recents and volumes; also the user's home folder in Locations | Start, dashboard | Accueil |
| Transfer | A copy, move or trash running with progress | Job, operation, task | Transfert |
| Cut | Mark items to move on the next paste | — | Couper |
| Move to Trash | Send to the Trash, can be put back | Delete, recycle | Placer dans la corbeille |
| Delete Immediately | Remove for good, can't come back | Delete permanently, shred | Supprimer immédiatement |
| Status bar | Line under the list with counts and free space | Footer, info bar | Barre d'état |
| Locations | Sidebar section of mounted disks and servers | Devices, drives | Emplacements |
| Enclosing Folder | The folder that holds this one (⌘↑) | Parent, up | Dossier parent |
| Return opens items | Setting: Return opens instead of renaming | Windows mode, Enter mode | Retour ouvre les éléments |
| Paste | Put cut or copied items in this folder | Drop here, insert | Coller |
| Move Items Here | Paste that moves copied items (⌥⌘V) | Paste move, cut paste | Déplacer les éléments ici |
| Keep Both | Conflict answer: the new item gets "name 2" | Rename, duplicate | Garder les deux |
| Replace | Conflict answer: the item already there goes to the Trash | Overwrite | Remplacer |
| Skip | Conflict answer: leave this item out | Ignore, pass | Ignorer |
| Rename | Edit an item's name in place (Return or F2) | Edit name | Renommer |
| New Folder | Make "untitled folder" here (⇧⌘N) | Create folder | Nouveau dossier |
| New File | Make a file from a template here | Create file, new document | Nouveau fichier |
| Transfers | The toolbar popover with copies and moves under way | Jobs, queue, activity | Transferts |
| Tag | A Finder tag on an item, with a color for the seven standard ones | Label, color label | Tag |
| Filter | Narrow this folder's list by name as you type | Search (that's S-029, across folders) | Filtre |
| Search | Find items by name in this folder and its subfolders, or on This Mac, with Spotlight | Find, query | Recherche |
| Show in Enclosing Folder | Go from a result to its folder, with it selected | Reveal, open location | Afficher dans le dossier parent |
